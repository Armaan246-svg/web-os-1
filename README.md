
# WebOS Project

A simple web-based desktop built with HTML, CSS, and plain JavaScript. You can move windows around, type notes, use a calculator, and switch desktop themes.

## Features
* Draggable windows with basic focus depth
* Persistent notepad (saves automatically to local browser storage)
* Basic working calculator
* Custom theme switcher in the display settings
* Live taskbar clock

Just download the repository and open `index.html` in any web browser.
