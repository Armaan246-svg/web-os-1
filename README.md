# DeskSpace OS

A simple web desktop built with vanilla HTML, CSS, and JS.

## Features
- Draggable desktop windows
- Persistent scratchpad using browser localstorage
- Working calculator app
- Theme switcher (Dark, Cyber Purple, Retro Grey)
- Real-time taskbar clock
